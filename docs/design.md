# Desktop setup wizard

The welcome page uses a horizontal 3:1 forest illustration with separate Wilson and Willow sprites. The workshop has a second panoramic background. Original fan illustrations reference the supplied Don’t Starve: Newhome promotional style. All backgrounds, character cutouts, stickers and icons live in `assets/images/`.

The default theme pairs parchment surfaces with muted burgundy actions, slate-blue selections and charcoal ink. The dark theme uses slate surfaces, dusty rose actions and parchment text. Neucha supplies hand-lettered Cyrillic and Latin headings and button labels. Inter keeps instructions, paths and status messages readable. Beveled controls share large pointer and keyboard targets.

The wizard keeps Back and Next in a fixed footer and scrolls the form separately. A numbered step list appears at widths of 960 logical pixels and above when the text scale leaves enough room. Compact windows keep the step counter and progress bar. Choosing a different computer’s OS offers a two-step guide. On the host OS the nine-step local server setup remains available.

Test-rendered welcome and wizard screenshots are stored in `docs/screenshots/`.

The forest plays a brief mist and firefly animation on entry and pointer re-entry. Button labels respond to hover and press while the hit target stays fixed. Reduced motion keeps the scene still and preserves immediate color feedback.

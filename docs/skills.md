# Engineering roles

1. Flutter desktop: native Windows/Linux runners, localized Material 3, Provider and GoRouter, responsive layouts.
2. Dart systems: structured Process args, streams, async I/O, explicit timeout and lifecycle states.
3. DST: app 343050 vs 322330, official flags, Master/Caves, validated configuration and no invented keys.
4. Windows: Steam registry/library discovery, Unicode paths, user-level installer, private ACLs, no credential forms.
5. Linux: Steam Client plus distro-aware SteamCMD instructions, quoted shell paths, no automatic sudo or system services.
6. Product UX: first-time wizard, recoverable errors, one primary action, honest installation/network status.
7. Security: no token in JSON/CLI/exports, redacted logs, ZIP traversal checks, no shell interpolation.
8. QA/release: generator/repository/process/widget tests, native builds, screenshot review and documented live-test limits.
